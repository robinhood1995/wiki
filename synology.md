# <img src="/images/synology-dsm.png" width="50" style="vertical-align:middle;margin-right:4px">What's Synology?

Synology specializes in NAS devices, which are used for centralized data storage, file sharing, and backup in homes and businesses. The company also provides software solutions like its Synology Drive for file syncing and Synology Router Manager (SRM) for networking products.
